# References

Before any new format, Growth asks the owner for **3–5 varied references** (not five of the same). They live here so
the next brief starts from them instead of from zero. The PM curates this folder: stale references get a
`retired: <date> <why>` note, they are never deleted.

**How to store one:** one line per reference in this file (or one file per reference, with the image next to it):

`<link or image filename> · take this: … · not this: … · added by: <owner|growth> · <date>`

- **Take this:** the exact thing to borrow ("the bold two-word title", "first line is a question").
- **Not this:** what to leave behind ("not the clickbait arrow", "not the color").
- Images go in this folder with a short, descriptive filename.
